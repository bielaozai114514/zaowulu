## 1. 《夜行》· AI 短片

对应案例：`nocturne`

```
电影感赛博都市雨夜街道，湿透的柏油路反射霓虹招牌，青蓝与品红的光在积水上拉出
长条倒影，远处高架桥车灯拖成光轨，画面中一个穿深色雨衣的背影正走向纵深，兜帽
遮住半张脸，肩挎旧帆布包，细雨在灯光里形成可见的光锥，35mm 胶片颗粒，高对比，
以冷色调为主、暖橙为点缀，宽银幕构图，画面中不要出现任何文字
```

**要点**：人物必须是**背影**——正面人物是 AI 生成的老大难。构图留出上下安全边距，
方便在卡片（16:9）和详情页大图（16:9）之间复用。

## 2. 《东方异兽》· AI 插画

对应案例：`beasts`

```
赛博水墨风格插画，绢本底色泛出微弱冷光，一只东方异兽（青龙形态）盘踞于大面积
留白之上，鳞甲由细劲线条勾勒，身体局部透出青蓝与品红的霓虹光晕，背景极简，仅
有一抹淡墨远山与几缕数字化的光粒子，矿物颜料质感与发光科技感并置，整体低饱和，
仅一处朱砂红点缀，画面中不要出现任何文字
```

**要点**：这一张是"国风 + 赛博"的融合，不是纯赛博。如果出图偏纯科技风，
把「赛博水墨」改回「宋代院体画风格」，只保留「霓虹光晕」一个科技元素。
