# 造物录 · AIGC 成果展示站

纯原生 HTML / CSS / JS，零依赖、无构建步骤。双击 `index.html` 就能看。

```
aigc-showcase/
├── index.html              作品墙（首页）
├── case.html               案例详情页
├── about.html              关于页
├── assets/
│   ├── favicon.svg         站点图标
│   ├── css/style.css       全部样式
│   ├── js/data.js          ← 你唯一需要改的文件
│   ├── js/app.js           渲染逻辑，不用动
│   └── media/              图片放这里（现在是占位图）
├── tools/
│   ├── make-placeholders.py  占位图生成脚本（可删）
│   ├── cover-prompts.md      三张封面图的生成提示词
│   └── render-test.js        自动化测试（可删）
└── README.md
```

## 已内置的功能

- 首页：分类筛选、关键词搜索、统计概览
- 详情页：**左侧本页目录**（滚动自动高亮）、工具链、成品画廊、制作拆解、复盘、相关案例、上下篇
- 灯箱：点击放大，支持 `←` `→` 翻页、`Esc` 关闭
- 提示词一键复制
- 回到顶部按钮（滚动超过一屏后出现）
- 全站响应式（320px 起）、键盘可访问、可直接打印成 PDF

## 一、怎么新增一个案例

打开 `assets/js/data.js`，在 `CASES` 数组里复制一份现成对象，改内容即可。改完存盘，刷新浏览器就能看到。

```js
{
  id: "my-case",                    // 唯一标识，英文小写，用于详情页链接
  title: "《作品名》",
  subtitle: "一句话副标题",
  category: "AI 短片",              // 分类，首页筛选按钮按它自动生成
  year: "2026",
  date: "2026-10-03",               // 用于统计「最近更新」
  cover: "assets/media/cover.jpg",  // 封面图
  summary: "两三句话讲清这个成果是什么。会显示在卡片上。",
  tags: ["标签1", "标签2"],
  stack: ["即梦", "可灵", "剪映"],   // 用到的工具，显示在卡片底部
  tools: [                          // 详情页「工具链」区块，可省略
    { name: "即梦", role: "生成角色定妆照与场景分镜图" },
    { name: "可灵", role: "把静态分镜转成 5 秒视频片段" }
  ],
  specs: [                          // 详情页顶部那排关键指标
    { k: "片长", v: "1 分 32 秒" },
    { k: "生成图片", v: "200+ 张" }
  ],
  intro: "项目说明，一段话就行。",
  gallery: [                        // 成品展示，点开可放大
    { src: "assets/media/a.jpg", caption: "图片说明" }
  ],
  steps: [                          // 制作拆解，按顺序写
    {
      name: "步骤名",
      desc: "这一步做了什么、为什么这么做。",
      prompt: "用到的提示词，没有就留空字符串",   // 留空则整块不显示
      params: ["模型 即梦 3.0", "比例 16:9"]      // 关键参数
    }
  ],
  retro: {
    title: "复盘",
    items: [
      "第一条复盘。<strong>可以用 strong 标签加粗。</strong>",
      "第二条复盘。"
    ]
  }
}
```

改完不用动任何其他文件，首页的案例数、工具数、筛选按钮、搜索索引都会自动跟着变。

### ⚠️ 写作原则：只写拿得出证据的东西

图片、提示词、技术判断——这些是真实的，随便写。

但**数量、时长、倍数、成功率**这类具体指标，如果当时没有记录，就不要写。
「生成了 200 多张图」「提效 8 倍」「单条耗时从 40 分钟压到 5 分钟」——这种数字看着专业，
可一旦有人追问细节，你答不上来，整站的可信度就一起塌了。

替代写法：把指标换成**方法描述**。
- ❌「一共生成了 200 多张图，最终只用了 14 张」
- ✅「人物行走的镜头最容易出问题，其余场景基本一次可用」

`tools/render-test.js` 里有一组「自洽性检查」，会扫描页面文本，
一旦出现被标记为「未证实数据」的字符串就会报错。新增案例时如果手滑写了编造的数字，
跑一下测试就能发现（把新出现的可疑字符串加进 `BANNED` 数组即可）。

## 二、怎么换成你自己的图片

1. 把图片丢进 `assets/media/`（建议 JPG，封面控制在 1600px 宽以内、300KB 以内）。
   封面推荐尺寸 **1280×720 或 1600×900**，画廊图推荐 **1000×750（4:3）**，用工具压一下再放进来。
2. 把 `data.js` 里对应的 `cover` 和 `gallery[].src` 改成新文件名。
3. 目前 3 个案例的封面与画廊图**都已是真实生成的图**（`*-cover.jpg` / `*-1~3.jpg`），
   全部替换成你自己的作品时，直接覆盖同名文件即可。

图片比例建议：
- **封面 `cover`：16:9（建议 1600×900）** —— 首页卡片与详情页大图共用同一张，比例必须一致，否则会被裁两次。
- **画廊图 `gallery`：4:3（建议 1200×900）**。

比例不统一会被 `object-fit: cover` 裁切，主体尽量放画面中央。

## 三、改站点名和文案

`data.js` 最上面的 `SITE` 对象：

| 字段 | 作用 |
|---|---|
| `name` | 站名，显示在左上角和页脚 |
| `sub` | 站名后面的小字 |
| `hero.eyebrow` | 首页标题上方的小标签 |
| `hero.title` | 首页大标题 |
| `hero.lead` | 首页导语 |
| `notice` | 首页顶部公告条。**留空（`""`）会自动显示「最近更新 + 最新收录的案例」**，通常不用管。⚠️ 这里的内容访客能直接看到，不要写内部说明 |
| `contact` | 页脚的联系方式 |

## 四、本地预览

直接双击 `index.html` 就能用（所有资源都是相对路径）。

如果想让手机也能访问，在本目录下开一个本地服务：

```bash
python -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。
